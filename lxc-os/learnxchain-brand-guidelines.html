11 — Usage Rules
Do's & Don'ts

Guidelines to keep the LearnXChain brand consistent across all touchpoints.

✓ Do
  • Use Deep Blue (#0057C8) as the dominant brand color on light backgrounds
  • Use Neon Green (#5CDD2B) only as an accent — sparingly on dark surfaces
  • Pair gradient text only on dark or black backgrounds
  • Use Syne font for all headings and display text
  • Apply --ease-bounce for interactive lifts and button hovers
  • Use coloured shadows that match the element's fill color
  • Maintain 4px grid spacing throughout all layouts
  • Use border-radius: 999px for all pill-shaped buttons and badges
✕ Don't
  • Don't use Neon Green as a background on large areas — it overwhelms
  • Don't place gradient text on white or light backgrounds
  • Don't use generic fonts (Arial, Inter, Roboto) — Syne + DM Sans only
  • Don't use more than 3 brand colors in a single component
  • Don't add animations over 600ms — keep interactions snappy
  • Don't use pure black (#000) for card backgrounds — use #0D1B2A
  • Don't omit focus states — --brand-cyan ring is mandatory for a11y
  • Don't stretch or distort the chain-link logo mark
