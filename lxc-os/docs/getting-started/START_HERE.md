3. Click "No throttling" dropdown
4. Select "Fast 3G"
5. Reload page

3. Click "Analyze"
4. Check metrics:
   - **LCP**: Should be < 2.5s ✓
   - **FID**: Should be < 100ms ✓

## 🚨 TROUBLESHOOTING

### Problem: Build fails

**Solution**:

```bash
rm -rf node_modules .next
npm install
npm run build
```

### Problem: Pages look broken locally

**Solution**:

```bash
npm run dev    # Use dev server instead of start
# Visit http://localhost:3000
```

### Problem: Images not showing

**Solution**:

- Clear browser cache
- Check image paths
- Verify next/image is imported correctly

### Problem: Performance metrics not improving

**Solution**:

- Clear browser cache (Ctrl+Shift+Delete)
- Do a hard refresh (Ctrl+Shift+R)
- Check DevTools isn't throttling

### Problem: Need help with specific page

**Solution**:

1. Check docs/OPTIMIZATION_CHECKLIST.md
2. Review FRONTEND_PERFORMANCE_GUIDE.md
3. Look for your page in PERFORMANCE_SUMMARY.md
